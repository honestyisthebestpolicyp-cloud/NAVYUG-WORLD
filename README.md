# 🌍 NAVYUG WORLD - My Own Browser

A custom Python web browser built by **Navyug, a 10-year-old developer from India!**

## 🚀 Features

- ✨ **Dark Stealth Mode** - Black theme with cyan accents
- 📰 **13 Daily News Cards** - Curated news with images and full text
- 🔍 **Smart Search Bar** - Search Google or navigate to URLs directly
- 👤 **Profile Page** - View browser info and status
- 💙 **About Inventor** - Learn about Navyug's coding journey
- 🤖 **Google AI Customization** - Custom styling for search results
- 🔒 **Private & Secure** - Local browser experience

## 📋 Requirements

```
Python 3.7+
PyQt5
PyQtWebEngine
```

## 💻 Installation

### 1. Install Dependencies
```bash
pip install PyQt5 PyQtWebEngine
```

### 2. Run the Browser
```bash
python NAVYUG-WORLD-browser.py
```

## 🎮 How to Use

1. **Home Page** - Click "⌂ Home" to see curated news
2. **Search** - Type in search bar and press Enter
3. **Browse URLs** - Enter full URLs (e.g., google.com, github.com)
4. **View Profile** - Click "👤 Profile" to see browser info
5. **About** - Click "💙 About Inventor" to read Navyug's story

## 📦 Create .EXE (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed NAVYUG-WORLD-browser.py
```

Your .EXE will be in `dist/NAVYUG-WORLD-browser.exe`

## 🎨 Customization

Edit `NEWS_DATA` list to add your own news:
```python
NEWS_DATA = [
    ["TITLE", "IMAGE_URL", "DESCRIPTION"],
    ...
]
```
